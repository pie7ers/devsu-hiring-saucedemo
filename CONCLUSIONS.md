# CONCLUSIONS

## ENGLISH

1. The end-to-end purchase flow was successfully automated using Cypress.

2. The application allows a user to:
   - Authenticate successfully.
   - Add products to the shopping cart.
   - Complete the checkout process.
   - Finish the purchase and receive the expected confirmation message.

3. Assertions were implemented at critical checkpoints to ensure the business flow behaves as expected.

4. The framework was designed following the Page Object Model pattern to improve maintainability and readability.

5. Reporting capabilities were integrated to provide execution evidence and facilitate debugging in case of failures.

6. The solution can be extended easily to cover additional scenarios such as:
   - Invalid login.
   - Product removal from cart.
   - Checkout validation errors.
   - Different user roles.

## ESPAÑOL

1. Se ha automatizado con éxito el flujo de compra de principio a fin utilizando Cypress.

2. La aplicación permite al usuario:
   - Autenticarse correctamente.
   - Añadir productos al carrito de la compra.
   - Completar el proceso de pago.
   - Finalizar la compra y recibir el mensaje de confirmación esperado.

3. Se han implementado verificaciones en puntos de control críticos para garantizar que el flujo de negocio se comporte según lo esperado.

4. El marco se diseñó siguiendo el patrón «Page Object Model» para mejorar la mantenibilidad y la legibilidad.

5. Se integraron funciones de generación de informes para proporcionar pruebas de la ejecución y facilitar la depuración en caso de fallos.

6. La solución puede ampliarse fácilmente para abarcar escenarios adicionales, tales como:
   - Inicio de sesión no válido.
   - Eliminación de un producto del carrito.
   - Errores de validación al finalizar la compra.
   - Diferentes roles de usuario.
